# WatchSend 使用指南

> 手表端文件传输 · 用户手册

适用版本 1.8.1（versionCode 10801）　2026 年 11 月

## 1 关于本指南

本指南面向 WatchSend 的使用者，说明如何安装、连接、发送与接收文件，以及设置页每一个选项的实际作用。文中出现的按钮与菜单名称，均与 App 内当前语言下的显示一致；如果你切换过界面语言，请对照同一语种的版本来读。

本指南只讲怎么用，不涉及编译、打包与二次开发。开发环境、提交规范与语言包维护方法，见仓库中的 CONTRIBUTING 与 docs 目录。所有行为描述基于 1.8.1 的实际实现；由于云构建环境无法运行模拟器，个别手势的体感差异请以真机为准。

## 2 安装与首次启动

WatchSend 以 APK 形式分发，最低支持 Android 2.3（API 10），可安装在手表，也可装在手机上作为收发端。手表端通常通过 adb 安装，或由手机上的手表助手推送安装；装好后在应用列表里找到 WatchSend 打开即可，无需登录，也不依赖任何账号。

首次启动会请求通知与存储相关权限：通知用于在后台提示收到的文件与传输进度，存储用于把文件写进相册或历史目录。拒绝授权不会导致崩溃，但后台提示会缺失，部分接收路径也可能失败，建议全部允许。

首页顶部是服务开关，显示当前是“启动”还是“停止”，旁边是运行状态与本机地址。服务未启动时，其他设备扫描不到你；点一下启动，App 会在 53317 端口开启 HTTP 服务，并开始周期性的组播发现，此时才能收发。

## 3 界面与基本操作

首页自上而下依次是：状态与地址、设备列表、以及发送、接收记录、跨网、设置、日志几个入口。设备列表支持两种滚动方式——Wear OS 3 及以上可以拨动表冠，也可以直接用手指上下滑动；滑动时边缘卡片会缩小并降低透明度，用来提示当前位置。

- 点击卡片进入下一级页面；页面底部的返回按钮或系统返回都可以退出当前页。
- 默认开启软件内滑动返回：从屏幕左右边缘向内横向滑动（起手点要贴近边缘，约 16dp 以内），整页跟手缩小、淡出后退回上一页。全部页面都遵循同一套规则，包括各类全屏页、设备详情、PIN 键盘、已选文件与网页二维码页。若你更习惯系统返回，可在“设置 → 通用 → 启用软件内返回”里关闭，关闭后返回键恢复原样，滑动不再触发返回。
- 设置里的“界面缩放”可在 0.3x 到 2.5x 之间调整整个 App 的字体与控件大小，圆表觉得字挤时优先调这一项。
- 圆表建议开启圆屏优化；有下巴的圆表（如 Moto 360）再打开“底部避让”，避免按钮被切掉。

## 4 发送文件

发送分四步，顺序固定：选择内容、选择设备、确认发送、等待进度。中途可以返回上一级修改选择，已选条目会保留在待发送列表里。

1. 在首页点“发送”，弹出类型菜单：文件、媒体、应用、文件夹、文本、剪贴板。
2. 选中具体条目；文件与媒体可多选，应用与文件夹一次一个，文本与剪贴板直接取当前内容。
3. 回到设备列表，点目标设备；对方必须已启动服务，并处在同一网段或已完成跨网配置。
4. 等待进度条走完。成功有提示与震动，失败会显示错误码，可切到“日志”页看细节。

发送文本会以 LocalSend 的文本消息发出，对方在通知或会话里看到原文；剪贴板则是把当前剪贴板内容当作一段文本发出去，不会传图片。发送大文件时屏幕会保持常亮，结束后自动恢复省电逻辑。

## 5 接收文件

只要服务处于启动状态，同网段的其他设备就能发现你并向你发送。接收前会弹出确认页，列出对方名称、文件数量与总大小；可以选择接受或拒绝，拒绝会立即通知对方，不会让对方一直等待。

“快速保存”决定是否跳过这个确认，共三档：每次都询问、全部自动接收、仅收藏设备自动接收。默认是每次都询问，第一次使用建议保持默认，确认来源可信后再改成自动接收。

大文件支持断点续传：传输中断后重新发起，会从已经写入的位置继续，而不是从头再来。收到的图片与视频可按设置自动进入相册，其余文件默认写入历史记录，两者都能在设置里单独关闭。

## 6 网页端与跨网传输

### 6.1 网页端

服务启动后，同一局域网内的电脑用浏览器打开首页显示的地址（形如 http://192.168.1.100:53317），就能看到一个极简页面：可以拖拽上传文件、查看多文件进度，也能与手表互发剪贴板文本。首页的地址可以点击复制，也可以打开“网页端地址”显示二维码，手机扫码更快。

网页端的内置语言跟随浏览器，共 10 种：简体中文、繁体中文、英文、日文、韩文、德文、法文、西班牙文、俄文、葡萄牙文。App 端则是 52 种，两者覆盖面不同，网页端没有对应语种时会回退英文。

### 6.2 跨网传输

不在同一个局域网时，有两条路。密码模式：一方生成 6 位一次性密码，另一方在跨网页面输入即可连上，全程不需要公网 IP。直连模式：双方把端口通过 FRP、Ngrok 或 ZeroTier 暴露到公网，然后在手动输入框里填 IP:53317，直连速度取决于你的穿透通道。

跨网依赖第三方设施与你的网络环境，稳定性不由本 App 保证。若连接一直建立不起来，先在日志页确认对端地址与端口是否可达，再检查穿透服务是否在线。

## 7 历史记录

“接收记录”按时间倒序列出收发过的文件与文本，压缩包会带一个明显的压缩包标识。长按任意一条可以调出操作菜单；点击则查看详情或直接打开。

- 重新发送：把这条记录里的文件放回待发送列表，退回设备列表点设备即可再发，不必重新找目录。
- 分享：调用系统分享，把文件交给其他应用。
- 解压：仅压缩包可用，使用内置纯 Java 引擎解压，带路径穿越防护，不会写到目标目录之外。
- 删除：移除这一条记录，已保存到相册的文件不受影响。

## 9 常见问题

**表 2　常见现象与处理**

| 现象 | 处理 |
| --- | --- |
| 设备列表一直显示“暂无设备，请点击扫描” | 确认对方已启动服务且在同一 Wi-Fi；关掉路由器的 AP 隔离；点扫描重试；仍找不到就用手动输入 IP |
| 对方发送时全部报错 400 | 多为协议字段或 HTTPS 状态不一致：双方同时关闭 HTTPS，或升级到同一版本后重试，并在日志页看具体状态码 |
| 浏览器打不开网页端 | 确认服务已启动、端口没被其他程序占用、电脑与手表在同一网段；部分路由器默认禁止设备互访 |
| 按返回键没反应，或只弹一句提示 | 说明“启用软件内返回”处于开启状态；关闭它，系统返回即恢复正常 |
| 文字或按钮被圆表边缘裁掉 | 打开圆屏优化，必要时开启底部避让，并把界面缩放调小一档 |
| 息屏一段时间后收不到文件 | 检查“熄屏空闲暂停服务”是否被打开（默认关闭），并确认系统没有对 WatchSend 做电池优化限制 |
| 传输时电量掉得快 | 开启低性能模式；低电量且未充电时 App 会自动限速到 512KB/s |

## 10 安全、省电与已知限制

- 默认使用明文 HTTP，只适合可信局域网；需要加密时开启 HTTPS，并核对对端证书指纹。
- PIN 默认为 0000，建议改成自己的 4 位数字；跨网传输使用 6 位一次性密码，用完即失效。
- 危险后缀默认拦截 exe、bat、cmd、vbs、sh；白名单与黑名单都在设备长按菜单里管理。
- 省电有三层：低性能模式关闭大部分动画并限速 2MB/s；电量低于 15% 且未充电时限速 512KB/s；熄屏 3 分钟暂停服务（默认关闭，有传输时会自动顺延）。
- 已知限制：跨网功能依赖第三方设施，稳定性不保证；静默安装受 ROM 限制；部分老设备没有震动马达或旋转表冠；解压与手势表现只在小屏真机上验证过。
- 本项目以 MIT 协议开源，由 AI 辅助生成、经人工审阅与真机调优；按现状提供，不承诺适用性。
