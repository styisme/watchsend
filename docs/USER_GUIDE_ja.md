# WatchSend ユーザーガイド

> ウォッチでファイル転送・取扱説明書

対象バージョン 1.9.0（versionCode 10900）　2026 年 11 月

## 1 このガイドについて

本ガイドは WatchSend を使う方向けに、インストール、接続、送受信の手順と、設定画面の各項目が実際に何をするのかを説明します。ボタン名やメニュー名は、選択中の表示言語での表記に合わせています。表示言語を切り替えた場合は、同じ言語の版を参照してください。

扱うのは使い方だけで、ビルドやパッケージ化、改造の手順は含みません。開発環境や投稿規約、言語パックの保守はリポジトリの CONTRIBUTING と docs を参照してください。記述は 1.9.0 の実装に基づきます。クラウドのビルド環境ではエミュレーターを起動できないため、ジェスチャーの感触は実機で確認してください。

## 2 インストールと初回起動

WatchSend は APK で配布され、Android 2.3（API 10）以上で動作します。ウォッチにも、送受信用のスマートフォンにも入れられます。ウォッチへは通常 adb で、またはスマートフォン側のウォッチ補助アプリから転送してインストールします。インストール後はアプリ一覧から WatchSend を開くだけで、ログインもアカウントも不要です。

初回起動時に通知とストレージの権限を求められます。通知は受信ファイルや転送進捗をバックグラウンドで知らせるために、ストレージはファイルをギャラリーや履歴フォルダーへ書き込むために使います。拒否しても落ちませんが、バックグラウンド通知が欠け、受信に失敗する経路もあります。両方許可することを勧めます。

ホーム画面の上部がサービスの切り替えで、「起動」か「停止」、稼働状態と自機アドレスが表示されます。停止中は他の機器から見つかりません。起動すると 53317 番ポートで HTTP サービスを開き、定期的なマルチキャスト探索を始めます。この状態で初めて送受信できます。

## 3 画面と基本操作

ホーム画面は上から順に、状態とアドレス、デバイス一覧、そして送信・受信記録・クロスネット・設定・ログの各入口です。一覧は 2 通りにスクロールできます。Wear OS 3 以降ではリューズを回せますし、指で上下に払うこともできます。スクロール中は端のカードが縮み、透明度が下がって現在位置を示します。

- カードをタップすると 1 階層下へ進みます。画面下部の戻るボタンでも、システムの戻るでも現在のページを離れられます。
- アプリ内のスワイプ戻るは既定で有効です。画面端から横に払うと、ページが指に追従して縮み、フェードして前のページへ戻ります。システムの戻るが好みなら、「設定 → 一般 → アプリ内戻るを有効化」を切ってください。切るとシステムの戻るが元に戻り、スワイプは戻る動作をしなくなります。
- 設定の「表示サイズ」は 0.3x から 2.5x までアプリ全体の文字と部品の大きさを変えます。丸い画面で窮屈に感じたら、まずこれを調整してください。
- 丸型ウォッチでは丸画面の最適化を有効にしてください。下部に張り出しのある機種（Moto 360 など）では「下部余白」も有効にすると、ボタンが欠けません。

## 4 ファイルの送信

送信は 4 手順で、順序は固定です。内容を選ぶ、デバイスを選ぶ、送信を確定する、進捗を待つ。途中で戻って選択を変えられ、選んだ項目は送信待ち一覧に残ります。

1. ホーム画面で「送信」をタップすると、種類メニューが開きます。ファイル、メディア、アプリ、フォルダー、テキスト、クリップボードです。
2. 項目を選びます。ファイルとメディアは複数選択でき、アプリとフォルダーは 1 つずつ、テキストとクリップボードは現在の内容をそのまま使います。
3. 一覧に戻り、送信先をタップします。相手はサービスを起動済みで、同じネットワーク上にあるか、クロスネットの設定が済んでいる必要があります。
4. 進捗バーが終わるまで待ちます。成功時は通知と振動、失敗時はエラーコードが出て、「ログ」画面で詳細を確認できます。

テキストは LocalSend のテキストメッセージとして送られ、相手は通知や会話で本文を見ます。クリップボードは現在の内容を 1 つのテキストとして送るもので、画像は送りません。大きなファイルの転送中は画面を点けたままにし、終了後に省電力を元に戻します。

## 5 ファイルの受信

サービスが起動していれば、同じネットワークの機器があなたを見つけて送信できます。受信前に確認画面が出て、相手の名前、ファイル数、合計サイズが並びます。受け入れるか断るかを選べ、断ると相手へすぐ通知され、待たせたままにはなりません。

「クイック保存」はこの確認を省くかどうかを 3 段階で決めます。毎回確認、すべて自動受信、お気に入りのみ自動受信です。既定は毎回確認で、最初はそのまま使い、送信元を信頼できてから自動に切り替えてください。

大きなファイルは中断しても再開できます。中断後に送り直すと、すでに書き込んだ位置から続き、最初からやり直しません。受信した写真と動画は設定に従ってギャラリーへ、それ以外は履歴へ書き込まれ、どちらも設定で個別に切れます。

## 6 ウェブ画面とクロスネット転送

### 6.1 ウェブ画面

サービス起動後、同じ LAN のパソコンのブラウザーでホーム画面のアドレス（例 http://192.168.1.100:53317）を開くと、最小限のページが表示されます。ファイルをドラッグして送信でき、複数ファイルの進捗も見え、ウォッチとクリップボードのテキストをやり取りできます。ホーム画面のアドレスはタップでコピーでき、「ウェブ URL」を開くと QR コードが出てスマートフォンで読み取れます。

ウェブ画面の内蔵言語はブラウザーに従い 10 種類です。簡体中国語、繁体中国語、英語、日本語、韓国語、ドイツ語、フランス語、スペイン語、ロシア語、ポルトガル語。アプリ本体は 52 言語で、対応が無い場合は英語に戻ります。

### 6.2 クロスネット転送

同じ LAN にいない場合、経路は 2 つです。パスワード方式では、片方が 6 桁の使い捨てコードを発行し、もう片方がクロスネット画面で入力すればつながります。グローバル IP は不要です。直接接続方式では、FRP、Ngrok、ZeroTier などでポートを公開し、手動入力欄に IP:53317 を入れます。速度は通り抜ける経路によります。

クロスネットは第三者の設備とあなたの回線に依存するため、安定性は本アプリでは保証しません。つながらない場合は、まずログ画面で相手のアドレスとポートに到達できるか、次に通り抜けサービスが稼働しているかを確認してください。

## 7 履歴

「受信記録」は送受信したファイルとテキストを新しい順に並べ、ZIP には圧縮ファイルの印が付きます。長押しで操作メニュー、タップで詳細かファイル本体を開けます。

- 再送：その記録のファイルを送信待ち一覧へ戻します。一覧に戻ってデバイスをタップすれば再送でき、フォルダーをたどる必要はありません。
- 共有：システムの共有でファイルを他のアプリへ渡します。
- 展開：圧縮ファイルのみ可能で、内蔵の純 Java エンジンを使い、経路逸脱（path traversal）対策があるため対象フォルダーの外へは書き込みません。
- 削除：その記録を消します。ギャラリーへ保存済みのファイルは影響を受けません。

## 9 よくある問題

**表 2　症状と対処**

| 症状 | 対処 |
| --- | --- |
| 一覧が「デバイスなし、スキャンを押してください」のまま | 相手のサービスが起動済みで同じ Wi-Fi かを確認する。ルーターの AP アイソレーションを切る。スキャンを再試行する。それでも出なければ IP を手動入力する |
| 相手からの送信がすべて 400 で失敗する | プロトコル項目か HTTPS の状態が食い違っている。双方で HTTPS を切り、または同じバージョンへ揃えて再試行し、ログ画面で状態コードを見る |
| ブラウザーでウェブ画面が開かない | サービス起動済み、ポートが他のアプリに取られていない、パソコンとウォッチが同じサブネットかを確認する。機器間通信を既定で禁じるルーターもある |
| 戻るキーが効かない、または通知が 1 つ出るだけ | アプリ内戻るが有効になっている。切ればシステムの戻るが通常どおり働く |
| 文字やボタンが丸い縁で欠ける | 丸画面の最適化を入れ、必要なら下部余白も入れ、表示サイズを 1 段下げる |
| 画面消灯からしばらくして受信できない | アイドル時のサービス停止が入っていないか（既定はオフ）、システムが WatchSend を電池最適化していないか確認する |
| 転送中に電池がすぐ減る | 低性能モードを入れる。電池 15% 未満かつ充電中でない場合、アプリは自動で 512KB/s に絞る |

## 10 安全、省電力、既知の制限

- 既定は平文 HTTP で、信頼できる LAN 向けです。暗号化が必要なら HTTPS を入れ、相手の証明書指紋を確認してください。
- PIN の既定は 0000 です。自分の 4 桁に変えてください。クロスネットは 6 桁の使い捨てコードで、使用後に失効します。
- 危険な拡張子 exe、bat、cmd、vbs、sh は既定で遮断します。ホワイトリストとブラックリストは機器の長押しメニューで管理します。
- 省電力は 3 段階です。低性能モードはほとんどのアニメーションを止め 2MB/s に制限します。電池 15% 未満かつ未充電では 512KB/s、画面消灯 3 分でサービスを止めます（既定オフ、転送中は延長）。
- 既知の制限：クロスネットは第三者設備に依存し安定性は保証できません。サイレントインストールは ROM の制限を受けます。古い機種には振動モーターやリューズが無い場合があります。展開とジェスチャーは小型の実機でのみ確認しています。
- 本プロジェクトは MIT で公開し、AI の支援で生成したものを人手で確認し実機で調整しています。現状のまま提供し、適合性は保証しません。
