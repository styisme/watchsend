# WatchSend 使用指南

> 手錶端檔案傳輸 · 使用者手冊

適用版本 1.7.13（versionCode 10713）　2026 年 11 月

## 1 關於本指南

本指南對象為 WatchSend 的使用者，說明如何安裝、連線、傳送與接收檔案，以及設定頁每一個選項的實際作用。文中出現的按鈕與選單名稱，都與 App 在目前語言下的顯示一致；若你切換過介面語言，請對照同一語種的版本閱讀。

本指南只談操作，不涉及編譯、封裝與二次開發。開發環境、提交規範與語言包維護方式，請見儲存庫中的 CONTRIBUTING 與 docs 目錄。所有行為描述基於 1.7.13 的實際實作；由於雲端建置環境無法執行模擬器，個別手勢的體感差異請以實機為準。

## 2 安裝與首次啟動

WatchSend 以 APK 形式發佈，最低支援 Android 2.3（API 10），可安裝在手錶，也可裝在手機上作為收發端。手錶端通常透過 adb 安裝，或由手機上的手錶助理推送安裝；裝好後在應用程式清單裡找到 WatchSend 開啟即可，不需登入，也不依賴任何帳號。

首次啟動會要求通知與儲存相關權限：通知用於在背景提示收到的檔案與傳輸進度，儲存用於把檔案寫進相簿或歷史目錄。拒絕授權不會導致當機，但背景提示會缺失，部分接收路徑也可能失敗，建議全部允許。

首頁頂端是服務開關，顯示目前是「啟動」還是「停止」，旁邊是執行狀態與本機位址。服務未啟動時，其他裝置掃描不到你；點一下啟動，App 會在 53317 連接埠開啟 HTTP 服務，並開始週期性的群播探索，此時才能收發。

## 3 介面與基本操作

首頁自上而下依序是：狀態與位址、裝置清單，以及傳送、接收記錄、跨網、設定、日誌幾個入口。裝置清單支援兩種捲動方式——Wear OS 3 以上可以轉動錶冠，也可以直接用手指上下滑動；滑動時邊緣卡片會縮小並降低透明度，用來提示目前位置。

- 點擊卡片進入下一層頁面；頁面底部的返回按鈕或系統返回都可以離開目前頁面。
- 預設啟用軟體內滑動返回：從螢幕邊緣橫向滑動，整頁跟手縮小、淡出後退回上一頁。若你更習慣系統返回，可在「設定 → 一般 → 啟用軟體內返回」關閉，關閉後系統返回恢復原樣，滑動不再觸發返回。
- 設定裡的「介面縮放」可在 0.3x 到 2.5x 之間調整整個 App 的字型與控制項大小，圓錶覺得字太擠時優先調這一項。
- 圓錶建議開啟圓屏最佳化；有下巴的圓錶（如 Moto 360）再開啟「底部避讓」，避免按鈕被切掉。

## 4 傳送檔案

傳送分四步，順序固定：選擇內容、選擇裝置、確認傳送、等待進度。中途可以返回上一層修改選擇，已選項目會保留在待傳送清單裡。

1. 在首頁點「傳送」，跳出類型選單：檔案、媒體、應用程式、資料夾、文字、剪貼簿。
2. 選中具體項目；檔案與媒體可多選，應用程式與資料夾一次一個，文字與剪貼簿直接取目前內容。
3. 回到裝置清單，點目標裝置；對方必須已啟動服務，並處於同一網段或已完成跨網設定。
4. 等待進度條走完。成功有提示與震動，失敗會顯示錯誤碼，可切到「日誌」頁看細節。

傳送文字會以 LocalSend 的文字訊息送出，對方在通知或會話裡看到原文；剪貼簿則是把目前剪貼簿內容當作一段文字送出，不會傳圖片。傳送大檔案時螢幕會保持常亮，結束後自動恢復省電邏輯。

## 5 接收檔案

只要服務處於啟動狀態，同網段的其他裝置就能發現你並向你傳送。接收前會跳出確認頁，列出對方名稱、檔案數量與總大小；可以選擇接受或拒絕，拒絕會立即通知對方，不會讓對方一直等待。

「快速儲存」決定是否跳過這個確認，共三檔：每次都詢問、全部自動接收、僅收藏裝置自動接收。預設是每次都詢問，第一次使用建議保持預設，確認來源可信後再改成自動接收。

大檔案支援中斷續傳：傳輸中斷後重新發起，會從已寫入的位置繼續，而不是從頭再來。收到的圖片與影片可依設定自動進入相簿，其餘檔案預設寫入歷史記錄，兩者都能在設定裡單獨關閉。

## 6 網頁端與跨網傳輸

### 6.1 網頁端

服務啟動後，同一區域網路內的電腦用瀏覽器開啟首頁顯示的位址（形如 http://192.168.1.100:53317），就能看到一個極簡頁面：可以拖曳上傳檔案、檢視多檔案進度，也能與手錶互傳剪貼簿文字。首頁的位址可以點擊複製，也可以開啟「網頁端位址」顯示 QR Code，手機掃碼更快。

網頁端的內建語言跟隨瀏覽器，共 10 種：簡體中文、繁體中文、英文、日文、韓文、德文、法文、西班牙文、俄文、葡萄牙文。App 端則是 52 種，兩者覆蓋面不同，網頁端沒有對應語種時會回退英文。

### 6.2 跨網傳輸

不在同一個區域網路時，有兩條路。密碼模式：一方產生 6 位一次性密碼，另一方在跨網頁面輸入即可連上，全程不需要公網 IP。直連模式：雙方把連接埠透過 FRP、Ngrok 或 ZeroTier 暴露到公網，然後在手動輸入框填 IP:53317，直連速度取決於你的穿透通道。

跨網依賴第三方設施與你的網路環境，穩定性不由本 App 保證。若連線一直建立不起來，先在日誌頁確認對端位址與連接埠是否可達，再檢查穿透服務是否在線。

## 7 歷史記錄

「接收記錄」依時間倒序列出收發過的檔案與文字，壓縮檔會帶一個明顯的壓縮包標示。長按任一筆可以叫出操作選單；點擊則檢視詳情或直接開啟。

- 重新傳送：把這筆記錄裡的檔案放回待傳送清單，退回裝置清單點裝置即可再傳，不必重新找目錄。
- 分享：呼叫系統分享，把檔案交給其他應用程式。
- 解壓縮：僅壓縮檔可用，使用內建的純 Java 引擎解壓，具備路徑穿越防護，不會寫到目標目錄之外。
- 刪除：移除這筆記錄，已儲存到相簿的檔案不受影響。

## 9 常見問題

**表 2　常見現象與處理**

| 現象 | 處理 |
| --- | --- |
| 裝置清單一直顯示「暫無裝置，請點擊掃描」 | 確認對方已啟動服務且在同一 Wi-Fi；關閉路由器的 AP 隔離；點掃描重試；仍找不到就用手動輸入 IP |
| 對方傳送時全部回報錯誤 400 | 多為協定欄位或 HTTPS 狀態不一致：雙方同時關閉 HTTPS，或升級到同一版本後重試，並在日誌頁看具體狀態碼 |
| 瀏覽器打不開網頁端 | 確認服務已啟動、連接埠沒被其他程式佔用、電腦與手錶在同一網段；部分路由器預設禁止裝置互訪 |
| 按返回鍵沒反應，或只跳出一個提示 | 表示「啟用軟體內返回」處於開啟狀態；關閉它，系統返回即恢復正常 |
| 文字或按鈕被圓錶邊緣裁掉 | 開啟圓屏最佳化，必要時開啟底部避讓，並把介面縮放調小一檔 |
| 熄屏一段時間後收不到檔案 | 檢查「熄屏閒置暫停服務」是否被開啟（預設關閉），並確認系統沒有對 WatchSend 做電池最佳化限制 |
| 傳輸時電量掉得快 | 開啟低效能模式；低電量且未充電時 App 會自動限速到 512KB/s |

## 10 安全、省電與已知限制

- 預設使用明文 HTTP，只適合可信區域網路；需要加密時開啟 HTTPS，並核對對端憑證指紋。
- PIN 預設為 0000，建議改成自己的 4 位數字；跨網傳輸使用 6 位一次性密碼，用完即失效。
- 危險副檔名預設攔截 exe、bat、cmd、vbs、sh；白名單與黑名單都在裝置長按選單裡管理。
- 省電有三層：低效能模式關閉大部分動畫並限速 2MB/s；電量低於 15% 且未充電時限速 512KB/s；熄屏 3 分鐘暫停服務（預設關閉，有傳輸時會自動順延）。
- 已知限制：跨網功能依賴第三方設施，穩定性不保證；靜默安裝受 ROM 限制；部分舊裝置沒有震動馬達或旋轉錶冠；解壓縮與手勢表現只在小螢幕實機上驗證過。
- 本專案以 MIT 授權開源，由 AI 輔助產生、經人工審閱與實機調校；依現況提供，不承諾適用性。
