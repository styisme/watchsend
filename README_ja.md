## ✨ 主な機能
- **リューズ入力**: Wear OS 3+の回転リューズに完全対応。
- **ダイナミックカラー**: Android 12+のMaterial Youに対応。
- **アンビエントモード**: 画面オフ時はプログレスバーのみ表示。
- **音声入力**: システムの`RecognizerIntent`をサポート。
- **無限UIスケーリング**: 0.3xから2.5xまでサイズを調整可能。
- **クロスネットワーク**: 6桁のPIN、P2P、UPnP / STUN / IPv6。
