## ✨ 核心特性
- **錶冠滑動支援 (Rotary Input)**: 完美適配 Wear OS 3+ 旋轉錶冠。
- **動態取色**: Android 12+ 接入 Material You。
- **息屏微光模式**: 息屏僅保留進度條，抬腕恢復。
- **語音輸入**: 支援系統語音轉文字。
- **無級 UI 縮放**: 0.3x ~ 2.5x 即時調整。
- **跨網穿透**: 6 位密碼、P2P 直連、UPnP / STUN / IPv6。
