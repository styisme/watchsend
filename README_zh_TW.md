## ✨ 核心特性
- **錶冠滑動 (Rotary Input)**: 完美適配 Wear OS 3+ 旋轉錶冠。
- **動態取色**: Android 12+ 接入 Material You。
- **極客工具箱 (v1.3.0)**: 支援 Shizuku/Root 靜默安裝、原生 ZIP 解壓、歷史記錄快捷管理。
- **Web 端 10 語種**: 自動識別瀏覽器語言，支援拖拽上傳。
