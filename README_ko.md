## ✨ Core Features / 核心特性
- **로터리 입력**: Wear OS 3+ 회전 크라운에 완벽하게 적용.
- **다이내믹 컬러**: Android 12+ Material You 통합.
- **앰비언트 모드**: 화면이 꺼져 있을 때 진행률 표시줄만 표시.
- **음성 입력**: 시스템 `RecognizerIntent` 지원.
- **무한 UI 스케일링**: 0.3x에서 2.5x까지 크기 조정 가능.
- **크로스 네트워크**: 6자리 PIN, P2P, UPnP / STUN / IPv6.
