## ✨ Core Features / 核心特性
- **表冠滑动支持 (Rotary Input)**: 完美适配 Wear OS 3+ 旋转表冠。
- **动态取色**: Android 12+ 接入 Material You。
- **息屏微光模式**: 息屏仅保留进度条，抬腕恢复。
- **语音输入**: 支持系统语音转文字。
- **无级 UI 缩放**: 0.3x ~ 2.5x 实时调整。
- **跨网穿透**: 6 位密码、P2P 直连、UPnP / STUN / IPv6。
