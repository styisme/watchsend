## ✨ Возможности

### ⌚ Оптимизация для часов
- **Поворотная головка** (Wear OS 3+), **тактильная отдача**, экран не гаснет при передаче, голосовой ввод, плитки (Android 7.0+).
- **Режим низкой производительности**: отключает почти все анимации (3D-колесо, появление, нажатие, бегущая загрузка, «дыхание» трёх точек, мерцание скелетона, переход переключателя, отскок панели), снижает параллелизм резервного поиска и ограничивает скорость. Включается сам на слабых устройствах (куча ≤256 МБ / low-RAM / ≤2 ядра), если его не настраивали вручную.
- **Ограничение скорости**: 2 МБ/с в режиме низкой производительности, 512 КБ/с при заряде ниже 15 % без зарядки — и на отправку, и на приём.
- **Пауза при простое (по умолчанию выключена)**: через 3 минуты после выключения экрана HTTP- и multicast-слушатели останавливаются и возобновляются при включении; при активной передаче пауза переносится.

### 🛠️ Инструменты гика
- **Тихая установка (бета)**: Root или Shizuku, собственный прокси Binder IPC.
- **Собственное распаковывание ZIP**: чистый Java-движок с защитой от path traversal.
- **История**: долгое нажатие — **отправить снова**, поделиться, распаковать, удалить. «Отправить снова» возвращает файл в список отправки.
- **Веб на 10 языках**: определяет язык браузера, перетаскивание и синхронизация буфера обмена.

### 🎨 Интерфейс и языки
- Физическое масштабирование UI (0,3x–2,5x), три состояния темы, динамический цвет Android 12+, 3D-колесо, адаптация под круглый экран, свайп назад.
- **52 языка полностью**: не менее 353 локализованных записей на язык, всего 18 403, без «сырых» ключей. Два текста «Включить возврат в приложении» из 1.7.13 есть во всех 52 языках; четыре из 1.7.12 — только в 10 базовых.
- **Загрузка языков по требованию**: при старте только базовые пакеты, остальные создаются один раз после выбора языка (экономия ~1 МБ кучи и времени запуска). См. [руководство по языкам](docs/LANGUAGES.md).
- **Wear-Uikit**: 44 нативных Java-виджета + 6 полноэкранных контейнеров, без внешних зависимостей.

### 🌐 Сеть и совместимость
- 6-значный одноразовый PIN, FRP/Ngrok/ZeroTier, UPnP/STUN/IPv6.
- Полная совместимость с LocalSend v1/v2.2, от Android 2.3 (API 10), белый/чёрный списки и блокировка опасных расширений.

## 📱 Быстрый старт
1. **Часы**: та же Wi-Fi, запустить службу, устройства находятся сами, нажать для отправки.
2. **Веб**: открыть `http://<IP часов>:53317` в браузере.
3. **Вне локальной сети**: 6-значный PIN или прямое подключение `[IP]:53317`.

## 🚧 Ограничения и риски
1. Работа вне локальной сети зависит от сторонних сервисов или собственной публичной конфигурации.
2. У части старых устройств нет вибромотора или головки; плитки — с Android 7.0.
3. Android 2.3 поддерживает только TLS 1.0: HTTPS не сработает.
4. 3D-эффекты требуют GPU; режим низкой производительности включается сам и может быть включён принудительно.
