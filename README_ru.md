## ✨ Основные функции
- **Поворотный ввод**: Идеально адаптирован для вращающейся головки Wear OS 3+.
- **Физическое масштабирование UI**: Реконструкция базового Context для обхода ограничений Android 11+ и поддержки от 0.3x до 2.5x.
- **Трехпозиционная тема**: Следовать системе, Светлая, Темная.
- **Динамический цвет**: Интеграция Material You (Android 12+).
- **Инструментарий гика**: Тихая установка Shizuku/Root, встроенная распаковка ZIP и быстрое управление историей.
- **Web 10 языков**: Автоматически определяет язык браузера и поддерживает загрузку перетаскиванием.
