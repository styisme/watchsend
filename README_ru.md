## ✨ Основные функции
- **Поворотный ввод**: Идеально адаптирован для вращающейся головки Wear OS 3+.
- **Динамический цвет**: Интеграция Material You (Android 12+).
- **Режим Ambient**: Минимальный интерфейс с индикатором выполнения при выключенном экране.
- **Голосовой ввод**: Поддержка системного `RecognizerIntent`.
- **Бесконечное масштабирование UI**: Размеры от 0.3x до 2.5x.
- **Кросс-сеть**: 6-значный PIN, P2P, UPnP / STUN / IPv6.
